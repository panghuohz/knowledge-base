# 数据建模规范（通用）

> 适用范围：通用 ｜ 维护人：待定 ｜ 最后更新：2026-09-04

## 流程
业务/流程 → 实体识别 → 字段与类型 → 关系（1:1 / 1:N / N:M）→ 唯一键/索引 → 枚举登记 → 回写实体文档

## 原则
- 先查 90-项目实例 既有实体与通用骨架，避免重复造表
- 字段命名与术语表一致
- 必备字段：id、created_at、updated_at；软删可选 deleted
- 状态用 tinyint，取值含义登记到实体文档与术语表
- 金额用 decimal，禁止 float
- 表结构变更先评审再落库，并同步实体文档
