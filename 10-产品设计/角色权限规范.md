# 角色与权限规范（通用模板）

> 适用范围：通用 ｜ 维护人：待定 ｜ 最后更新：2026-09-04

## 设计步骤
1. 列出角色：终端用户 / 业务方 / 运营 / 管理员（按项目实际增减）
2. 确定权限模型：RBAC（角色-权限）或更细粒度
3. 整理权限点清单：菜单 / 按钮 / 接口 三级
4. 明确数据权限范围：本人 / 本部门 / 全部

## 产出物
- 角色清单、权限点清单（表格）
- 登录后权限如何下发（角色 / 权限码 / 前端路由守卫）

## 注意
- 权限点先定义后编码，避免边写边加
- 具体项目的角色与权限点写进 90-项目实例/<项目>/ 下对应文件
