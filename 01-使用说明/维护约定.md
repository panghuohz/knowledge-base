# 维护约定

> 适用范围：本知识库 ｜ 维护人：待定 ｜ 最后更新：2026-09-04

## 边界
- 01-使用说明 ~ 70-技能流程：通用骨架，只放跨项目可复用的规范、模板、流程。
- 90-项目实例：具体项目的档案、业务流程、数据模型、术语表。
- 通用骨架不得被单个项目“写死”；项目特有内容一律进 90-项目实例。
- 个人角色（前端/后端/全栈）是项目级属性：只记录在项目 AGENTS.md 或项目档案，不进入通用骨架。

## 纪律
- 每个文件顶部标注 适用范围 / 维护人 / 最后更新。
- 变更即回写：改表、改接口、定错误码的当天更新，不许攒。
- 公共规范影响所有项目：改动前写明“为什么改、影响谁”。
- 文件要小：一个文件讲一件事，宁多勿长。
- 敏感信息（客户资料、密钥、账号）禁止入库；项目实例同样遵守。
- 文档随代码同步：改了实现必须同步更新对应文档，避免 AI 读到过期规范。

## Codex 使用方式
- 在 KnowledgeBase 仓库内：Codex 自动读取根目录 AGENTS.md。
- 在项目仓库内：把 01-使用说明/项目-AGENTS.md模板.md 复制为根目录 AGENTS.md，声明角色并引用本知识库。
- 角色切换 = 不同项目各自声明角色，知识库骨架保持不变。

## 流程
- 通用结论：先讨论再写入 01~70，并同步 README 的目录说明。
- 项目结论：写入 90-项目实例/<项目>/ 对应文件。
