# 维护约定

> 适用范围：本知识库 ｜ 维护人：待定 ｜ 最后更新：2026-09-04

## 边界
- 01~70 是通用骨架：只放跨项目可复用的规范、模板、流程。
- 90-项目实例 放具体项目知识：档案、业务流程、数据模型、术语表。
- 通用骨架不得被单个项目“写死”；项目特有内容一律进 90-项目实例。

## 纪律
- 每个文件顶部标注 适用范围 / 维护人 / 最后更新。
- 变更即回写：改表、改接口、定错误码的当天更新，不许攒。
- 公共规范影响所有项目：改动前写明“为什么改、影响谁”。
- 文件要小：一个文件讲一件事，宁多勿长。
- 敏感信息（客户资料、密钥、账号）禁止入库；项目实例同样遵守。

## 流程
- 通用结论：先讨论再写入 01~70，并同步 README 的目录说明。
- 项目结论：写入 90-项目实例/<项目>/ 对应文件。
