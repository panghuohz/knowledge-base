# 开场指令模板（配合 Codex）

> 说明：若项目仓库根目录已有 AGENTS.md，Codex 会自动读取，无需手动贴本模板。本模板用于尚未配置 AGENTS.md 的仓库或临时会话。

## 用法
把以下内容发给 Codex，替换 <任务描述> 与 <相关范围>，并明确「本次我的角色」：

---
通用知识库：C:\Users\25733\Documents\外包项目\99_共享资源\KnowledgeBase

本次我的角色：<前端 / 后端 / 全栈 / 架构 / 评审>
本次任务：<任务描述>
涉及范围：<如：数据模型 / 接口 / 前端页面 / 后端模块>

请按角色先读取知识库相关文件（见下表），再开始；若产出新增表结构、接口或规范结论，收尾前回写知识库；项目专属内容写 90-项目实例，通用结论写通用骨架。
---

## 角色声明的标准格式（用户主动告知时可直接这样发）
- 我的角色：前端开发（本仓库只负责 xxx 模块；后端另有其人 / 或也是我）
- 负责范围：搜索页、房源详情、消息中心
- 技术栈：微信小程序 + 云开发
- 协作方：后端同事 / 甲方自有团队 / 全栈一人

> 若你未声明角色、且项目 AGENTS.md 里也没有：Codex 应**主动询问以上四项**后再开工，不得假设角色。

## 按角色读取路径（相对知识库根）
| 本次角色 | 优先读取 |
| --- | --- |
| 前端 | 40-前端/、60-界面设计/、30-接口API/（调用侧） |
| 后端 | 50-后端/、20-数据模型/、30-接口API/（设计侧） |
| 全栈/架构 | 70-技能流程/平台类项目全流程.md 通读后分步 |
| 评审/救火 | 90-项目实例/<项目>/项目档案.md + 相关模块 |

## 小技巧
- 任务范围越小，让 Codex 读的文件越少越准。
- 跨模块大任务：先让 Codex 读 70-技能流程/平台类项目全流程.md 再分步。
- 正式项目建议直接用 01-使用说明/项目-AGENTS.md模板.md 代替本模板（自动读取，无需每次粘贴）。
