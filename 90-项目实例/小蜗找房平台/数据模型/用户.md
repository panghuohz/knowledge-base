## 字段
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | bigint | 是 | 主键 |
| phone | varchar | 是 | 手机号（登录账号） |
| nickname | varchar | 否 | 昵称 |
| avatar | varchar | 否 | 头像 URL |
| status | tinyint | 是 | 状态：0 禁用 1 正常 |
| created_at | datetime | 是 | 创建时间 |
| updated_at | datetime | 是 | 更新时间 |
