# 前端规范总览

> 适用范围：前端 ｜ 维护人：待定 ｜ 最后更新：2026-09-04

前端按端划分：小程序 / Web / App。三者共享一部分通用规范，其余按平台不同。

## 结构
- 00-通用/：跨端通用（目录原则、组件、命名、Git）
- 小程序/小程序规范.md
- Web/Web规范.md
- App/App规范.md

## 怎么选（配合角色声明中的技术栈）
| 本项目的技术栈 | 主要阅读 |
| --- | --- |
| 微信小程序 / 云开发 | 00-通用 + 小程序/小程序规范.md |
| React / Vue 等 Web 应用 | 00-通用 + Web/Web规范.md |
| RN / Flutter / uni-app / 原生 App | 00-通用 + App/App规范.md |
| 多端同仓（小程序+App 复用代码） | 00-通用 + 小程序 + App（uni-app / Taro 场景） |

## 约定
- 通用规范每个平台都必须遵守；平台规范只约束该平台。
- 各平台规范均为「建议初稿」，按实际项目技术栈确认后回写。
- 界面视觉 / 组件风格另见 60-界面设计。
