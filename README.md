# Knowledge Base · 通用开发知识库

> 定位：跨项目复用的「通用模型」骨架。通用规范与流程放 01~70；具体项目的专属知识只放 90-项目实例，不污染通用骨架。

## 目录结构
- 01-使用说明/ 开场指令模板、AGENTS.md 模板、维护约定（先读这里）
- 10-产品设计/ 业务流程 / 角色权限 / 术语表（规范 + 模板）
- 20-数据模型/ 建模规范、实体文档模板
- 30-接口API/ API / 响应 / 分页 / 错误码 规范
- 40-前端/ 总览 + 00-通用（目录/组件/命名/Git）+ 平台规范（小程序 / Web / App）
- 50-后端/ Spring Boot / MySQL / Redis / 部署 规范
- 60-界面设计/ 设计系统 / 色彩 / 图标 / 页面模板
- 70-技能流程/ 全流程与各环节的可复用开发流程
- 90-项目实例/ 每个项目的档案与专属知识（项目级，不进骨架）

## 怎么用（配合 Codex）
0. 在项目仓库开发：把 01-使用说明/项目-AGENTS.md模板.md 复制为仓库根目录 AGENTS.md（Codex 自动读取，声明角色 + 引用本知识库）；本知识库根目录也有 AGENTS.md 维护指南。
1. 按任务读取对应模块规范（10~60）与技能流程（70）；前端先读 40-前端/总览.md，再按技术栈选 小程序/Web/App。
2. 涉及具体项目，读取 90-项目实例 里对应项目的档案与数据模型。
3. 收尾：新增的通用结论回写通用规范；项目专属结论回写 90-项目实例。

## 新项目接入（通用模型用法）
1. 项目仓库建好后，放入 AGENTS.md（用 01-使用说明 的模板），声明“我的角色/负责范围/技术栈”。
2. 在 90-项目实例 建立 <项目名>/ 文件夹：项目档案.md、业务流程.md、术语表.md、数据模型/。
3. 按 70-技能流程 执行开发，产物回写对应文件。
