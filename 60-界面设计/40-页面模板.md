# 页面模板（建议初稿，待确认）

> 适用范围：全端 UI ｜ 维护人：待定 ｜ 最后更新：2026-09-04

## 通用状态
空态 / 加载 / 错误 / 无权限 / 无数据 五类状态统一处理，不逐页自造。

## 标准结构
- 列表页：搜索区 + 筛选 → 列表（空态/加载/分页）→ 底部操作（如适用）
- 详情页：信息分组展示 → 状态说明 → 主操作按钮
- 表单页：分组 + 必填标记 → 校验提示 → 提交/取消（提交中禁用）
- 弹窗：标题 + 内容 + 主次按钮；点遮罩关闭需与需求确认

## 落地
- 尺寸/间距/圆角/颜色全部引用 10-设计Token规范.md 的 token（tokens.json），禁止硬编码。
- 各端差异（小程序/Web/App）按 40-前端 平台规范实施。
