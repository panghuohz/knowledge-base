# 基础样式规范（设计 Token · 建议初稿，待确认）

> 适用范围：全端 UI ｜ 维护人：待定 ｜ 最后更新：2026-09-04

统一用「语义 token」管理样式，代码里禁止硬编码数值/色值。命名示例：space-4、font-16、radius-8、color-primary。

## 布局与间距
- 以 4 为基准网格；间距阶梯：4 / 8 / 12 / 16 / 24 / 32。
- 页面左右安全边距（参考）：Web 16~24、小程序 32rpx、App 16dp；桌面内容区最大宽度 1200 居中。
- 卡片间距 12~16；区块间距 24~32。

## 字体
- 字号阶梯：12 / 14 / 16 / 20 / 24 / 32（正文默认 14~16，标题 20 起）。
- 字重：400 常规 / 500 中等 / 600 半粗，避免过细或过粗。
- 行高：正文 1.5、标题 1.3。
- 字体栈用系统默认（PingFang SC / Microsoft YaHei 等），不打包中文字体。

## 圆角
- 4：输入框、小元素；8：卡片、按钮；12：弹窗、大卡片；50%：头像/圆形标签。

## 阴影与层级
- 层级约定：0 平级 / 1 卡片浮起 / 2 下拉与弹层 / 3 全屏浮层。
- 阴影柔和、低透明度，颜色用半透明黑（具体取值随 20-色彩系统 确认）。

## 组件基准尺寸
- 按钮高度：大 48 / 中 40 / 小 32（逻辑值，按端换算）。
- 输入框高度与中按钮对齐（40）。
- 可点击区域最小 44（触屏友好）。

## 断点 / 响应式（Web/App 参考）
- <576 手机 / 576~992 平板 / >992 桌面（可按项目调整后回写）。
- 移动优先，桌面限制内容宽度。

## 深色模式（可选）
- 一律走语义 token 自动切换，禁止写死色值。

## 端适配（单位映射）
| 端 | 单位 | 说明 |
| --- | --- | --- |
| Web | px / rem | rem 需配根字号方案 |
| 小程序 | rpx | 以 750 设计稿为准，1px ≈ 2rpx |
| App | dp / 逻辑像素 | RN / Flutter 用框架单位 |

## 落地
- Web：CSS 变量 / design token 文件；小程序：app.wxss 公共变量；App：框架主题。
- 数值以本文件为唯一来源：改数值 = 改 token，不逐页改。
