# 界面设计规范总览

> 适用范围：全端 UI ｜ 维护人：待定 ｜ 最后更新：2026-09-04

界面规范按「先定 token、再做页面」组织：基础样式 → 色彩 → 图标 → 页面模板。

## 结构
- 10-基础样式规范.md：布局/间距/字体/圆角/阴影/层级/尺寸/断点（一套 token，全端共用）
- 20-色彩系统.md：主色/功能色/中性色/语义色
- 30-图标系统.md：图标来源/命名/尺寸
- 40-页面模板.md：列表/详情/表单/弹窗标准结构

## 用法
- 所有端共用同一套语义 token；端差异只发生在「单位与实现」层（见 10-基础样式规范/端适配）。
- 新项目开工：先按本项目实际 UI 确认 10 与 20 的取值，再让 Codex 按 token 开发页面。
- 代码落地（CSS 变量 / 主题文件）见 40-前端。
