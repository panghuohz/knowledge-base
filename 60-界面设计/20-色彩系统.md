# 色彩系统（语义名定义）

> 适用范围：全端 UI ｜ 维护人：待定 ｜ 最后更新：2026-09-04

语义色名在此定义；**取值一律放在 tokens.json**（见 10-设计Token规范.md）。本文件只维护“名字与用途”，不写具体色值，避免双份漂移。

## 语义色清单
| Token | 用途 |
| --- | --- |
| color-primary | 主色 / 主按钮 / 选中态 |
| color-success | 成功 |
| color-warning | 警告 |
| color-error | 错误 / 删除 |
| text-1 | 主文字 |
| text-2 | 次要文字 |
| text-3 | 占位 / 禁用 |
| border | 边框 / 分割线 |
| bg | 页面背景 |
| overlay | 遮罩 |

## 规则
- 取值只改 tokens.json；hover / active / disabled 由主色派生，统一在 token 层维护。
- 深色模式：同一组语义 token 对应一套 global 暗色取值（如 tokens.dark.json）。
- 正文与背景对比度 ≥ 4.5:1（参考）。
