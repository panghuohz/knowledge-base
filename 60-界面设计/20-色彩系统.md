# 色彩系统（建议初稿，待确认）

> 适用范围：全端 UI ｜ 维护人：待定 ｜ 最后更新：2026-09-04

## 命名
语义命名：color-primary / color-success / color-warning / color-error；文字 text-1/2/3；边框 border；背景 bg。

## 色板（示例值，需按实际品牌确认后替换）
| Token | 用途 | 示例值 |
| --- | --- | --- |
| color-primary | 主色/主按钮/选中态 | #1677ff（示例，待定） |
| color-success | 成功 | #52c41a（示例） |
| color-warning | 警告 | #faad14（示例） |
| color-error | 错误/删除 | #ff4d4f（示例） |
| text-1 | 主文字 | #1f2329（示例） |
| text-2 | 次要文字 | #646a73（示例） |
| text-3 | 占位/禁用 | #8f959e（示例） |
| border | 边框/分割线 | #e5e6eb（示例） |
| bg | 页面背景 | #f7f8fa（示例） |

## 规则
- 所有颜色用 token，禁止页面硬编码。
- hover / active / disabled 状态由主色派生，统一维护。
- 深色模式用同一组语义 token 切换，另维护一套暗色取值。
- 对比度满足可读性（正文与背景 ≥ 4.5:1 参考）。
